🚀 QUICK START (Read This):

1. BEFORE Installation:
   → Extract ZIP to temporary location
   → Read 00_START_HERE.txt
   → Read PILOT_CHECKLIST.md (sections A–D)

2. Installation:
   → Double-click: INSTALLER/KanzleiAI-Setup-0.1.0.exe
   → Follow Windows installer prompts
   → Installation path: C:\Program Files\KanzleiAI (default)
   → Data directory: C:\ProgramData\KanzleiAI (auto-created)

3. First Run:
   → Open console: cmd or PowerShell
   → cd "C:\Program Files\KanzleiAI"
   → Run: kanzlei_ai.exe serve
   → Setup wizard will ask for admin email + password
   → Database migrations will run automatically
   → Admin user will be created

4. Access Dashboard:
   → Open browser: http://127.0.0.1:8000/dashboard
   → Login with admin credentials
   → Change password (forced on first login)
   → Start using the system

Full Setup Details: PILOT_CHECKLIST.md (Sections A–J)
